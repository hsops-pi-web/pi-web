# v0.3

发布日期：2026-07-28

## 概要

`v0.3` 将 pi-web-auth 的生产运行基线统一到 Node.js 24，并已在生产环境上线到 standalone release `20260728-021119-b1ecc25`。

## 主要变更

- 将项目 Node.js 运行范围固定为 `>=24 <25`。
- 将已验证运行版本记录为 `v24.17.0`。
- 更新 GitHub Actions、systemd unit 模板、release 脚本、rollback 文档和 README 中的 Node 路径。
- 修复 release 测试对旧 Node 22 路径的隐式依赖，测试会使用当前 `process.execPath` 和当前 npm。
- 更新上游 Pi Web 升级优先级文档，明确 Node 24 已验证，不再建议 Node 22 基线。

## 同期合入的能力

- 管理员观测页面和相关 API。
- session index、workspace/tag API、session sidebar 增强和生产备份纳入 session index。
- 用户模型偏好和全局默认模型隔离。
- standalone 生产发布、健康检查、排空、备份、自动回滚和 staging verification 流程。
- 清理未使用的 FunASR 转写相关内容。

## 验证

- `npm run verify` 在 `spike/node24-compat` 分支通过。
- `npm run verify` 在合并后的 `main` 通过。
- 8144 隔离验收通过：`/login`、`/api/auth/me`、`/api/health/live`、`/api/health/ready`。
- standalone release build 和 staging verification 通过。
- 生产 8000 上线后 `/api/health/ready` 返回 ready，`/login` 返回 200。
