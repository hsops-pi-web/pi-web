# 服务端口迁移到 8000 设计

日期: 2026-06-08
分支: `main`

## 背景

Pi Web 之前使用旧的自定义端口。当前需要统一改为 `8000`，并让开发命令、生产启动命令、CLI 默认端口、systemd 服务和文档说明保持一致。

## 目标

- `npm run dev` 使用端口 `8000`
- `npm run start` 使用端口 `8000`
- `pi-web` CLI 在没有显式 `--port` / `PORT` 时默认监听 `8000`
- `pi-web.service` 正式服务监听 `8000`
- README、AGENTS、superpowers plan/spec 文档不再引用旧端口

## 非目标

- 不修改 Next.js build 流程
- 不改上传、下载、会话和模型逻辑
- 不删除旧分支或清理未跟踪本地文件

## 配置决策

| 配置点 | 新值 |
|--------|------|
| Dev server | `next dev -p 8000` |
| Production start | `next start -p 8000` |
| CLI default port | `8000` |
| systemd `PORT` | `8000` |
| systemd `ExecStart` | `--port 8000` |

## 验证

- 旧端口号无遗留配置引用
- `node_modules/.bin/tsc --noEmit` 通过
- `npm run build` 完成，`.next/` 生产构建包含端口变更
- `systemctl --user restart pi-web.service` 后服务为 active
- `curl http://localhost:8000/` 返回 `200`
- 旧端口不再由 `pi-web.service` 监听
