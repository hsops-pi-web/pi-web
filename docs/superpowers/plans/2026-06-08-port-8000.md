# 服务端口迁移到 8000 实施计划

**目标：** 将 Pi Web 的开发、生产、CLI 默认端口和 systemd 正式服务统一迁移到 `8000`。

**规格：** `docs/superpowers/specs/2026-06-08-port-8000-design.md`

## 任务 1：代码与脚本端口

- [ ] `package.json` 中 `dev` 改为 `next dev -p 8000`
- [ ] `package.json` 中 `start` 改为 `next start -p 8000`
- [ ] `bin/pi-web.js` 默认端口改为 `8000`
- [ ] typecheck / lint

## 任务 2：文档端口

- [ ] `README.md` 示例地址和 systemd 示例改为 `8000`
- [ ] `AGENTS.md` quick start 改为 `8000`
- [ ] 相关 superpowers plan/spec 文档改为 `8000`
- [ ] 扫描确认无旧端口遗留配置引用

## 任务 3：正式服务端口

- [ ] `npm run build`，确保 `.next/` 使用最新源码和端口配置
- [ ] 修改 `~/.config/systemd/user/pi-web.service`
- [ ] `Environment=PORT=8000`
- [ ] `ExecStart=... --port 8000`
- [ ] `systemctl --user daemon-reload`
- [ ] `systemctl --user restart pi-web.service`
- [ ] 验证 `http://localhost:8000/` 返回 200
- [ ] 验证 `pi-web.service` 为 active

## 任务 4：提交与确认

- [ ] 提交代码和文档变更
- [ ] 汇报端口迁移结果和服务访问地址
